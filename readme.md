# A Physics-Informed Neural Network Approach for Invasive Mechanical Ventilation Weaning Prediction in ICU Patients

### MSc Individual Research Project Report — Imperial College London

This project investigates whether combining clinical time-series data with established physiological principles can improve predictions of readiness for weaning from invasive mechanical ventilation. It develops and evaluates a physics-informed neural network using ICU patient data, with validation on an independent clinical dataset.
